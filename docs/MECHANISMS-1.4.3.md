# 机制、可逆性和证据边界

|1.4.2 已有|1.4.3 新增|不支持 / 待验证|
|---|---|---|
|Lin 旧版增强、2.8.2 Vertex 正文承接、2.9.0 原文核对；原手动补全、诊断与复制|本版开关不迁移任何旧偏好；新增实验详情单列|不承诺第三方别名对应哪款模型、也不保证永不截断|
|Accept 声明回复格式；纯搜索下的受限错序修复；旧标记 / 旧样本、被动读取|确认上一轮纯回显后，下一次手动尝试仅不再生成插件自己的辅助消息|没有第二种经验证的深度策略；主动工具输出未接入聊天|
|Lin 原有请求 nonce/roll，独立可配置的旧样本与同题复用|同源浏览器请求的临时随机头；独立的请求媒体类型补齐|真实缓存命中率、真实云模型文学效果均未测；不声称能改变路由|

### 1. 同题纯回显保护（标准）
输入：Lin 2.9.0、可证实的文字结构、已识别的 Google 适配器、确认原尾部、无网页搜索/扩展工具。普通发送或手动候选生成可观察回复。上一轮须只有一个可认领的发送、完整读取、正常结束码、没有拒答/限制/工具/续传或不明输出，且**全部文本**（允许首尾空白）等于本轮自己的辅助文本或样本。宽限为 180 秒。两轮的聊天、角色、用户消息、邻近历史、渠道和旧辅助设置要匹配；任何一项不明就放弃。不是按正则从剧情里删东西。

只在下一轮类型为 regenerate / swipe 且本来会创建独立区时，不再创建那一条 `messages[].role=system`，或不再创建原生 `systemInstruction.parts[]` 的那个块。不会向模型添加新的提示，正文散列不作为认领凭据。其余字段交给原承接逻辑。在正常发送和此后重试中，仍按旧设置运行。省略系统块可能改变这一次的提示缓存前缀，未测命中率。对照：同一输入，已证实回显后，旧版与新版关闭时都发原标记；标准时省略，其余消息完全相同。隔离接收端按固定规则返回文字，不是模型质量评分。

### 2. 请求和回复两个方向
`repairJsonMime` 只在可证明归属且序列化规范的 ST JSON POST、未指定 Content-Type、调用方只使用已核实的酒馆请求头时补一个 `Content-Type: application/json`。不写正文或其他参数。显式 text/plain、已有正确声明、原生封装、自定义渠道/不明结构不覆盖。撤销仅关闭这一个开关。正常 ST 已经声明 JSON，不推荐常开排查所有空回。

原 `protocolProfile` 管的是 `Accept`：浏览器希望**收到** SSE 或整段 JSON。在原来支持的纯搜索条件下也允许移动两条已核实的原文。这个旧行为不是上述请求类型修复。

### 3. 三种随机来源与传输核对
|来源|放哪里|生成/复用|影响模型输入？|
|---|---|---|---|
|预设 nonce 与 roll|Lin 原提示词|由 ST 展开，原样保留|原预设本来的行为|
|旧样本（macro）|本插件之前就有的独立系统区|8/16/24 个十六进制字符 × 1–3 组；保留原触发选择|会，因此模型有可能复述|
|新锚（traceAnchor）|同源酒馆生成 POST 的 X-Lin-Request-Id|WebCrypto 抽 16/24/32 个十六进制字符；同一已核实发送计划只抽一次，新的重生成/滑动重抽，继续不加|不写入提示。验证用的 ST 后端没有向 Google 请求转发该头|

调用方传入不明或带签名的头时整层跳过；已有同名头不给自己记功。只在初始同源请求上设置编号；其他环境的代理/重定向可能会转发它，重定向后的回包不作为纯回显证据。无回传记「未回传」；回传不符则这个回复仍交还酒馆，但本插件不将它作为同题回显证据，也不留作可复制正文；匹配只表明这次字段吻合，不是认证。随机跟踪与标准可单独开、同时开或全关。无官方逐项用量；只会展示渠道实际报告的**整轮**用量。本版不重复生成。新增功能对普通请求正文的最大增加是 0 字节；标准重试只可能减去旧独立区。旧样本字符和旧辅助区的出站净字节依然单独统计。

### 4. 适配与跳过矩阵
|请求形态|原有处理|1.4.3 增量|
|---|---|---|
|AI Studio / Vertex 的 ST messages，普通文字且尾部可证明|按旧设置核对|回显保护受结束原因约束；可核对追踪头/缺失请求类型|
|确认过同轮设置和发送的一致 Google contents + 独立 systemInstruction|同样验证尾部；不对任意 Google URL 拦截|纯回显机制有结构测试；两个 HTTP 实验不更改原生封装|
|Google 网页搜索开启|原「响应格式兼容」可处理符合原约束的纯搜索错序，其他情况保留原请求|新增三项跳过；无需永久关闭搜索|
|第三方 custom / 别名、已有工具及其历史、签名、MCP、多模态、结构化结果、原生预填充、缓存/续传状态、非规范正文、同轮冲突|仅按 1.4.2 自己的许可运行|不提交新版实验；不删数据或联机参数|
|continue / quiet / impersonate、聊天切换、取消、无法关联的请求|保留宿主或原插件行为|不借用别人的回包；不自行重试|

Argon、Carbon、Hydrogen、Neon 仅是识别器支持的别名族。实际本地酒馆走 makersuite 与 vertexai 两个构造器，模型字符串为 gemini-4-carbon，接收端为本机测试服务；没有真实模型鉴权、推理、名额或线上连接测试。不能从 model 字符串、格式或 200 推断后端型号、Google 安全策略、路由或计费。

### 5. 回包、隐私、撤销
JSON/SSE 只读诊断使用明确字段。外层错误码与响应体 error.code 分开；不会从剧情中的“503”推断错误。完整 STOP、达到长度、续传、仅 DONE、HTTP 错误、空字节、拒答字段、客户端读取/解析错误分别报告。只看到宿主停止事件不区分主动停止和错误停止。ST 1.19.1 Google 非流式翻译会丢上游 finishReason；宁可显示未知，也不当成 STOP。样本回显检测不是通用拒答检测。

2.9.0 管理流：由宿主的读取带动旁路统计，禁用时释放本版的定时器和暂存块，不取消宿主 reader。对其他插件后包裹的 fetch，仅将自己的壳停用。更老 Lin 的既有只读取证仍用 response.clone() 并读取副本来保留原 response 对象；**全插件所有旧路径均零预读**不是已实现的承诺。

分享入口只允许固定枚举、计数和状态。默认不导出编号、原文、签名、完整请求/地址或原文哈希；新诊断在页面内对照接口/保存文本指纹，持久化只保留比较结论，不破坏旧历史。原有的自定义提示与详细备份在另一个标明用途的折叠区。停用新实验恢复旧行为，无后台请求、云端服务或上传。

### 6. 本地输出研究
`output-lab.js` 与 `scripts/lab-text-143.mjs` 分别演示工具配对和文字定界。只有单一、完整、带结束证据的合成载荷可以读出；缺尾、混合工具、多个或冲突标记一概不猜。旧工具演示仅由本地自检按钮触发；新文字原型仅由测试导入。日常生成不调用它们，不注册外部工具、不创建自动续写，不把未生成/未返回的文字补成故事。
